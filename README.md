# 梯径(ladderpath)可视化平台

[立即打开在线平台](https://yuernestliu.github.io/Laddergraph-Visualization/)

这是一个面向 Laddergraph `.gv` / `.dot` 文件的纯前端交互式可视化工具。普通用户只需联网并使用现代浏览器，不需要安装 Node.js、npm、Python 或 Graphviz。

用户选择的图文件只在自己的浏览器中读取和渲染，不会上传到 GitHub 或其它服务器。

> 开发者入口：[开发环境与日常维护](docs/DEVELOPMENT.md) · [GitHub Pages 部署](docs/DEPLOYMENT.md) · [架构说明](docs/ARCHITECTURE.md)

## 普通用户使用

### 1. 打开平台

访问：<https://yuernestliu.github.io/Laddergraph-Visualization/>

页面会自动载入一份示例图及其节点信息，可以直接试用全部浏览功能。

### 2. 导入自己的图

- 点击左上角的文件选择框，选择 `.gv`、`.dot` 或 `.txt` 文件。
- 文件选中后会立即在浏览器中渲染。
- 点击 **渲染** 可以用当前文件和设置重新生成视图。

平台无法浏览或枚举电脑上的文件夹，只会读取用户明确选择的文件。

### 3. 导入节点信息

节点信息是一份“节点 ID → 详情或基因列表”的独立数据。点击 **导入节点信息** 后，可以选择 `.csv` 或 `.json` 文件。

支持以下格式：

| 格式 | 数据形状 |
| --- | --- |
| JSON（推荐） | `{"<节点id>": ["基因A", "基因B"]}` |
| 列式 CSV | 每一列表头是节点 ID，下面是该节点的基因 |
| 行式 CSV（旧） | 表头含“层级 / 梯元 / 梯元id / 重数”，最后一列是详情 |

浏览器不能自动读取用户所选 GV 文件旁边的 CSV，因此导入本地图后，需要再手动选择节点信息文件。

### 4. 选择布局

| 选项 | 适合场景 |
| --- | --- |
| 层级布局（下→上） | 默认的上下层级关系 |
| 层级布局（左→右） | 横向查看层级关系 |
| 分层布局（组成关系递推） | 更紧凑地查看组成关系 |
| 力导向布局 | 查看整体连接结构；大图可能较慢 |

选择后点击 **应用**。

### 5. 调整显示

- **文本**：选择都显示、只显示 ID 或不显示 Label。
- **字号**：使用 `-`、数字框和 `+` 调整 Label 字号。
- **节点尺寸**：可选择固定、`sqrt(S)`、`S^(1/3)`、`log(S+1)` 或 `S`。
- **隐藏小图**：控件“视图中隐藏 节点数<n 的图，n=”用于隐藏节点数小于 `n` 的连通图。`n` 最小为 2；可以直接选择参考值 `2`、`3`、`5`、`10`、`20`，也可以用 `-` 和 `+` 调整。

### 6. 切换网络与层级

- 每个标签页只显示一个连通图，并按节点数从大到小排列。
- 网络较多时，标签会自动变成下拉选择框。
- **浅1层**：隐藏一层最底层。
- **深1层**：补回一层最底层。
- **合适层级**：自动选择适合浏览的层数。
- **全部层**：恢复完整层级。

切换网络时，各标签页会保留自己的缩放位置和选中节点。

### 7. 缩放、平移和节点高亮

- 使用图区右上角的 `+`、`-` 和 **适中** 调整视图。
- 在图的空白处按住并拖动可以平移。
- 点击节点后，选中节点显示为深红色，上游使用红色系，下游使用绿色系。
- 再次点击同一节点或点击空白处，可以取消高亮。

### 8. 查看与导出节点信息

- 点击节点后，右侧面板会显示该节点的信息。
- 点击 **导出当前梯元 CSV** 可以导出当前节点的基因列表。
- 按住 `Ctrl`（macOS 可用 `Command`）再点击第二个节点，可以导出两个节点的所有集、交集和并集。
- 导出文件使用 UTF-8 with BOM，适合直接用 Excel 打开。

### 9. 精修与编辑模式

**精修模式**可以关注、隐藏、折叠或展开节点，也可以只查看关注节点及其直接邻居。精修只改变当前显示，不会修改原始 `.dot` 文件。

**编辑模式**目前只是模式入口，尚未提供实际编辑功能。

## 隐私与性能

- Graphviz 在浏览器的后台 Worker 中运行，使用访问者设备的 CPU 和内存。
- 用户导入的图和节点信息不会为了渲染而上传。
- 普通和中型图通常可以顺畅运行；特别大的图可能需要较长时间或较多内存。
- 单次布局计算默认最多运行 60 秒。
- 同一标签页的渲染结果会被缓存，长时间浏览很多大图会增加内存占用。

## 当前限制

- 编辑模式尚无实际编辑功能。
- 目前没有滚轮缩放。
- 网页不能枚举本地目录，也不能自动读取用户所选 GV 旁边的 CSV。
- 万级节点图的文件解析仍可能短暂占用页面主线程。
- 极大图可能受到浏览器内存和 60 秒渲染上限影响。
